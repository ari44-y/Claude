- 前日の夜には出さない
- 種類が混ざっていると回収されない

## 収集曜日（中町1丁目）

品目一覧の「収集日」の欄は、次の曜日に読み替える。

| 品目一覧の「収集日」 | 曜日 |
|---|---|
| もやすごみの日 | 毎週 水・土 |
| もやさないごみの日 | 毎週 火 |
| 資源物の日 | 毎週 月 |
| 申込み制 | 粗大ごみ。事前に申し込み、指定された日に出す（決まった曜日はない） |
| 収集しません | 市では収集しない。「出し方など」の欄の方法（業者相談、リサイクル家電の処分など）に従う |

## 収集の休み

- 11月23日（勤労感謝の日）
- 12月31日〜1月3日
- 上記以外の祝日は通常どおり収集する

## 全般のルール

- **粗大ごみ**：1辺が40センチメートル以上のもの。有料（1点400円のシール）・事前申込制。申し込み方法は戸田市「粗大ごみについて」のページを参照
- **プラマーク容器包装**：プラマークがあり、軽くすすいで汚れが落ちるもの。汚れたものや、プラマークのないプラスチック製品は「もやすごみ」になる（品目一覧の「(注釈1)」はこのこと）
- **ペットボトル**：中身を空にし、キャップとラベルを外してすすぎ、つぶして、もやさないごみの日に青いかごへ入れる。キャップとラベルは素材に応じて別に出す
- **危険物（2026年4月から変更）**：リチウムイオン電池などの二次電池と、40センチメートル未満の小型家電は、透明な袋に入れて、もやさないごみの日に赤いかごへ出す
- **リサイクル家電**（エアコン・テレビ・冷蔵庫・洗濯機・衣類乾燥機）とパソコンは、市では収集しない
- 家庭ごみの直接持ち込みと、事業活動で出たごみを集積所に出すことはできない
